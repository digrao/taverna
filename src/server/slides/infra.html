Budget Guard budget.ts

1
Frontmatter do projeto declara budget_usd_daily: 0.50
2
Antes de spawnar o agente, checkBudget() lê 60_Agents/4_Config/costs.json
3
Se custo acumulado do dia ≥ limite → retorna BUDGET: ... sem consumir tokens
4
Após run bem-sucedido, recordCost() appenda no ledger com retenção de 90 dias
5
No dia seguinte o acumulado reseta — não bloqueia permanentemente

Policy Resolver policy-resolver.ts

Permissões resolvidas em cadeia do mais geral ao mais específico:
📜 agent.permissions declarado no frontmatter da diretiva do agente
📂 inferProjectTools(target) Write, Edit, Read — sempre que target existe
🔧 Bash(git *) adicionado se target/.git existir
Com permissions: usa modo default + --allowedTools explícito.
Inferência de ferramentas do target é aplicada.
Sem permissions: usa bypassPermissions (padrão).
Inferência NÃO ocorre — agente tem acesso irrestrito.

Active Runs & Sessão active.ts

Enquanto o agente roda
// /tmp/taverna-active/PSI3451.json
{"project":"PSI3451",
 "agent":"@study-assistant",
 "sessionId":"<uuid>",
 "startedAt":"2026-05-23T…"}
Arquivo removido ao terminar. O server observa o diretório com fs.watch e emite agent_active via SSE.
Gestão de sessão
1
Executor gera sessionId (UUID) antes de spawnar
2
Escreve _session_id + _session_started nas tasks pendentes
3
Passa --session-id ao claude
4
Se ACTION_REQUIRED: humano retoma com claude --resume <sessionId>

Ciclo Completo de Gestão

Vault (frontmatter)
    projeto: run_every, budget, pipeline, agent, tasks
        ↓ scanVault() + isProjectDue() + checkBudget()
    executor: resolvePolicy → buildPrompt → spawnClaude
        ↓ claude --print --output-format json (stdin)
    claude CLI: executa, produz RESULTADO: ou ACTION_REQUIRED:
        ↓ parseResult() + recordCost() + log(agent_run)
    vault update: _last_run, _last_status, _runs_total, logbook
        ↓ stdout JSON → journal → promtail → Loki
    Grafana: dashboards de custo, saúde e throughput
        ↓ taverna serve SSE → browser
    dashboard: cards por projeto, ações, stream ao vivo
