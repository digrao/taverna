Definir o schema de configuração do taverna.

Requisitos:
- nada hardcoded
- configurável via JSON no momento do build
- o JSON deve ser autodocumentado (campos com descrição inline)
- plugins podem declarar suas próprias chaves de config

Resultado: um JSON Schema anotado que serve como documentação viva.
