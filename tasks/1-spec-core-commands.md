Definir todos os comandos que o core deve implementar, independente de protocolo.

Cada comando deve ter:
- nome
- descrição
- parâmetros (nome, tipo, obrigatório)
- retorno esperado

Esses comandos são a fonte de verdade — HTTP, MCP e CLI apenas os expõem.
